# Trend-forecasting 📈

> Extracting useful insights from 48,000 gamers' discussions to forecast trends.

## 💡 项目简介 (Introduction)
本项目旨在通过分析来自 48,000 名玩家的大规模讨论数据（`voices.jsonl`），提取有价值的观点与趋势，从而实现对游戏/行业趋势的有效预测。

## 📂 文件结构 (File Structure)
- `run.py`：核心预测与数据处理程序。
- `voices.jsonl`：包含 4.8 万条玩家评价与讨论的样本/数据集。
